# مرکز فرماندهی (Command Center) ⚡
> اپلیکیشن مدیریت ماموریت‌ها، تمرکز عمیق و برنامه‌ریزی شخصی با رویکرد سرعت فوق‌العاده، قدرت اجرایی و تعاملات مبتنی بر جسچر (Gesture-First).

---

## 🚀 ویژگی‌های پیاده‌سازی‌شده در فازهای ۱ تا ۵ (Complete Command Center)

### ۱. معماری و سیستم طراحی پویا (Power Dynamic Design System)
- **پالت رنگی دوگانه (تیره قدرتمند و روشن مینیمال):**
  - **تم تیره قدرتمند (Power Dark):** پس‌زمینه اولیس Obsidian `#090A0F` و تاریکی عمیق `#050608` با کارت‌های کریستالی `#13151D`.
  - **تم روشن مینیمال (Crisp Light):** پس‌زمینه شفاف `#F8FAFC` و کارت‌های سفید برفی `#FFFFFF` با کنتراست فوق‌العاده.
- **رنگ‌های اکشن و قدرت:**
  - **Neon Emerald (`#10B981` / `#059669`):** انجام ماموریت‌ها و پیروزی با درخشش نئونی
  - **Electric Amber (`#F59E0B` / `#D97706`):** ماموریت‌های اصلی (Boss Tasks) با اولویت بالا
  - **Sunrise Sky Blue (`#38BDF8` / `#0284C7`):** انتقال به فردا، زمان استراحت و برنامه‌ریزی
  - **Indigo / Purple (`#6366F1` / `#A855F7`):** بخش تمرکز، مرور شبانه و پروژه‌ها
- **تایپوگرافی فارسی اصیل:** فونت Vazirmatn در ۴ وزن (Regular, Medium, SemiBold, Bold) به همراه ارقام فارسی در تمام رابط کاربری.
- **چیدمان تماماً راست‌به‌چپ (Full RTL Layout):** تنظیم دقیق جریان بصری و اکشن‌های جسچر.

### ۲. نوار ناوبری پایینی و دکمه چندمنظوره (Omni-Add `+`)
دارای ۴ تب اصلی + دکمه مرکزی شناور Omni-Add (`+`):
1. **امروز (Today):** صفحه اصلی با نوار تسلط، ماموریت‌های Boss، جریان کارها، عادت‌ها و بنر مرور شبانه بعد از ساعت ۲۰:۰۰.
2. **برنامه (Plan):** هاب استراتژیک برنامه‌ریزی (تقویم جلالی، تایم‌بلاک ساعتی، صندوق ایده و پروژه‌ها).
3. **دکمه شناور مرکز (`+`):**
   - **لمس تکی (Single Tap):** شیت سریع ثبت ماموریت با NLP (تاریخ، ساعت، زمان، هشتگ) و چیپ‌های تاریخ.
   - **نگه‌داشتن طولانی (Long Press):** ثبت صوتی با شکل‌موج انیمیشنی (`expo-audio`).
4. **تمرکز (Focus):** هاب جامع تمرکز عمیق (Focus Command Hub) با آمار تلمتری و لانچر سریع جلسات.
5. **عملکرد (Stats):** هاب جامع تله‌متری، نمودارهای هفتگی تعاملی، رتبه‌های فرماندهی و دفترچه پیروزی‌ها.

### ۳. موتور تقویم شمسی مستقل (Pure TypeScript Jalali Engine)
- پیاده‌سازی مستقل در `src/utils/jalali.ts` بر مبنای الگوریتم روزهای ژولینی بدون وابستگی به باگ‌های `Intl`.
- تبدیل دوطرفه میلادی ↔ شمسی (`toJalali`, `toGregorian`).
- پشتیبانی کامل از ایام هفته (شنبه تا جمعه)، تقویم بازشونده ماهانه و برچسب‌های نسبی.

### ۴. حالت قفل تمرکز و اجرای ماموریت (Lock-In / Execution Mode) ⚡
- پس‌زمینه تاریک مطلق (`#050608`)، حلقه زمان‌سنج دایره‌ای با `react-native-svg` و بدون لرزش ارقام (`tabular-nums`).
- میکسر صداهای پس‌زمینه (باران، کافه، نویز سفید)، روشن ماندن صفحه (`expo-keep-awake`) و نوتیفیکیشن پس‌زمینه.
- فینال قدرت — دکمه «تمامش کردم!» با لرزش هپتیک دوگانه، ذخیره آمار و انیمیشن جشن پیروزی.
- نوار شناور مینی‌تایمر (`MiniFocusBar`) حین مرور سایر صفحات.

### ۵. هاب عملکرد و تله‌متری قدرت (Tab 4: Stats & Victory Log)
- **کارت قهرمان رتبه فرماندهی (Hero Card):**
  - پیشرفت در ۵ رتبه: `شروع‌کننده` (۰-۲۰۰ XP)، `منظم` (۲۰۰-۶۰۰ XP)، `مبارز تمرکز` (۶۰۰-۱۵۰۰ XP)، `استراتژیست` (۱۵۰۰-۳۵۰۰ XP) و `فرمانده کل` (+۳۵۰۰ XP).
  - نوار پیشرفت درخشان XP تا رتبه بعدی.
  - وضعیت شتاب لحظه‌ای (Momentum): `در حال گرم شدن`، `⚡ در جریان`، `🔥 تمرکز بالا`، `👑 توقف‌ناپذیر`.
  - شمارنده استریک روزانه متوالی (`🔥 X روز متوالی`) و بهترین رکورد تاریخچه.
- **شبکه ۴ کارته بنتو (Bento KPI Grid):**
  - پیروزی‌های این هفته، زمان کل تمرکز عمیق، نرخ تسلط بر ماموریت‌های اصلی، و اوج قدرت (پربازده‌ترین روز هفته).
- **نمودار هفتگی تعاملی (Interactive SVG Weekly Bar Chart):**
  - نمودار میله‌ای ۷ روز هفته (شنبه تا جمعه) با قابلیت تغییر بین «ماموریت‌ها» و «دقایق تمرکز».
  - لمس هر میله باعث نمایش تولتیپ شناور و اطلاعات دقیق آن روز می‌شود.
- **ماتریس انضباط عادت‌ها (Habit Matrix Grid):**
  - نمایش نقطه‌ای وضعیت اجرای عادت‌های سریع در ۷ روز هفته شمسی.
- **دفترچه پیروزی‌ها (Victory Log Feed):**
  - لاگ زمانی ماموریت‌های فتح‌شده و جلسات تمرکز به همراه امتیاز XP کسب‌شده و مدت زمان.

### ۶. آیین مرور شبانه (Nightly Command Review Ritual) 🌙
فرآیند جمع‌بندی پایان روز در ۳ گام انیمیشنی سریع (۱۵ ثانیه):
1. **جشن پیروزی‌های امروز:** مرور دستاوردها، دقایق تمرکز و ثبت سطح انرژی/حس روزانه (Mood Score از ۱ تا ۵).
2. **پاکسازی کارهای باقیمانده (Sweep):** انتقال یک‌لمسی تمام کارهای ناتمام امروز به فردا با دکمه درخشان پاکسازی.
3. **آماده برای فردا:** پیش‌نمایش ماموریت‌های فردا و پیام انگیزشی رهایی ذهن برای خواب آرام.
- فعال‌سازی از طریق بنر بعد از ساعت ۲۰:۰۰، اعلان محلی در زمان دلخواه یا کلید بالای صفحه عملکرد.

### ۷. تنظیمات پیشرفته و امنیت داده‌ها (Settings & Data Safety)
- انتخابگر تم تیره / روشن با اعمال بلادرنگ در تمام برنامه.
- فعال/غیرفعال‌سازی سراسری ویبره لمسی (Haptics) و افکت صوتی پایان کار (Completion Chime).
- زمان‌بندی ساعت اعلان مرور شبانه (از ۲۰:۰۰ تا ۲۳:۳۰).
- انتخاب تقویم شمسی (جلالی) یا میلادی.
- **خروجی JSON (Export JSON):** کپی در کلیپ‌بورد و اشتراک‌گذاری کل داده‌های ذخیره‌شده.
- **بازیابی JSON (Import JSON):** بازخوانی سریع نسخه پشتیبان با اعتبارسنجی ساختار فایل قبل از جایگزینی.

### ۸. معرفی اولیه و پل داده ویجت (Onboarding & Widget Bridge)
- مدال خوش‌آمدگویی ۳ اسلایدی تعاملی (`OnboardingModal`) برای کاربران جدید با امکان رد شدن سریع.
- سرویس `widgetSyncService.ts` با ذخیره‌سازی داده‌های فشرده جهت ارتباط با ویجت‌های نیتیو اندروید (Glance) و iOS (WidgetKit).

## 🏃 نحوه اجرا و بررسی پروژه

```bash
# ۱. اجرای سرور توسعه Expo:
npx expo start

# ۲. اجرای تحت مرورگر وب:
npx expo start --web

# ۳. بررسی کامل سلامت کدها و بدون خطا بودن تایپ‌ها:
npx tsc --noEmit

# ۴. خروجی گرفتن فایل نصبی اندروید (APK) در فضای ابری EAS:
eas login
eas init
eas build --platform android --profile preview
```
